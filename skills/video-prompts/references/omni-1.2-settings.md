# Настройки запроса Omni 1.2 и расхождения между сервисами

Модель: `gemini-omni-1.2-flash`. Запросы идут через Interactions API.

## Поля запроса (Gemini API)

| Поле | Значения | По умолчанию |
|---|---|---|
| `response_format.duration` | целые секунды, `3s`-`15s`; больше - ошибка | `10s` |
| `response_format.aspect_ratio` | `16:9`, `9:16` | `16:9` |
| `response_format.resolution` | `360p`, `720p`, `1080p` и `4k` (увеличение готового) | `720p` |
| `response_format.delivery` | `uri` для роликов тяжелее 4 МБ | |
| `generation_config.thinking_level` | `low`, `high` | |
| `generation_config.video_config.task` | `text_to_video`, `image_to_video`, `reference_to_video`, `edit`, `extend` | не задан |
| `previous_interaction_id` | ход правки или продления своего ролика | |

`task` добавляет жёсткие ограничения на число и сочетание файлов. Google советует сначала пробовать без него.

`360p` рендерится примерно вдвое быстрее: это черновик для проверки промпта перед чистовым рендером.

## Чего у модели нет

Не писать в промпт и не обещать в настройках:

- отдельного поля отрицаний;
- системной инструкции;
- звука на вход в Gemini API: ни дорожки, ни образца голоса;
- форматов кадра, кроме двух названных;
- ссылки YouTube как источника.

## Расхождения между сервисами

Перед тем как упереться в лимит, выясни, через какой сервис пойдёт запрос. Цифры ниже расходятся в самих источниках, а не устарели.

| Что | Gemini API | Google Cloud | Flow | Посредники |
|---|---|---|---|---|
| Опорных картинок | до 6 | до 10 на промпт | ингредиенты через `@имя` | у Segmind до 10 |
| Потолок продления | 30 с | 40 с | шаг 3-10 с | |
| `seed` | в документации нет | `generation_config.seed` | | у Segmind есть |
| Звук-опора | нет | по списку допуска | голос `@Voice: <имя>`, только с ингредиентами | |
| `temperature`, `top_p` | не поддержаны | значатся в таблице модели | | |
| Формат кадра не задан | 16:9 | выводится из промпта | | |
| Длина ролика | 3-15 с | 3-15 с | без подписки 3-10 с, с подпиской до 15 | |
| Пара кадров и продление | есть | есть | только в веб-версии | |

Flow: `@имя` - это имя ингредиента, которое он получил в интерфейсе Flow, а не снятый тег. В промпте стоят настоящие имена, не придуманные, и роль каждого ингредиента всё равно названа словами. Какие разрешения предлагает Flow, в источниках не найдено.

Где есть `seed`: удачный черновик закрепляют тем же `seed` и рендерят выше. Тот же `seed` вместе с дословным описанием героя Google советует для постоянства между роликами.

Посредник Replicate: начальный и конечный кадр не совмещаются с опорными картинками; видео на вход не совмещается с картинками; при правке длина и формат кадра берутся у исходника.

Сторонние обёртки местами ещё принимают управляющие теги. Google называет их устаревшими и обещает отключить; в новых промптах их нет.

Запрет на людей у Google звучит как «certain recognizable people»; практики упирались в него со знаменитостями. Про фото частных людей документация запрета не называет. Картинки с детьми закрыты в ЕЭЗ, Швейцарии и Великобритании.
