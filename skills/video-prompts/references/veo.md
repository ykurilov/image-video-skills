# Veo 3.1

Сведения на 10 ноября 2026. Источники и степень надёжности - в отчёте исследования, ссылка внизу.

## Версии и доступ

Новейшая модель - Veo 3.1, Veo 4 нет. Пользователь работает через Higgsfield (CLI `higgsfield`):

| Модель в CLI | Что это | Когда брать |
|---|---|---|
| `veo3_1`, `variant: veo-3-1-preview` | Полная Veo 3.1 | Чистовой ролик, речь, звук |
| `veo3_1`, `variant: veo-3-1-fast` | Fast, стоит по умолчанию | Черновик; для чистового переключать явно |
| `veo3_1_lite` | Lite, предварительная версия | Дёшево, с первым и последним кадром |

- Ролик Veo - один момент длиной 4, 6 или 8 с. Длинная история собирается из нескольких роликов.
- Все тесты таймкодов, найденные в источниках, сделаны на Fast. Полную модель этим не мерили.

## Умолчания модели

| О чём промпт молчит | Что сделает модель |
|---|---|
| Звук | Подберёт речь, шумы и музыку сама; у `veo3_1_lite` звука нет, пока не включён `generate_audio` |
| Надписи на вывесках и предметах | Выдуманные слова |
| Фоновые люди | Смотрят на главного героя, если их действие не описано |
| Подробности сцены | Додумывает сама; Veo нужны точные указания, расплывчатый промпт даёт случайный результат |

## Как читает промпт

- Порядок Google: камера и план → субъект → действие → место и контекст → стиль и атмосфера. Звук отдельными предложениями после картинки.
- Камеру, объектив и свет называть кинотерминами: тип плана, движение, фокусное расстояние, время суток.
- Отрицания вида «no» и «don't» не писать. Нежелательное убрать описанием нужной картины.
- Предел промпта - 1024 токена. Официально поддержан только английский.
- Картинка→видео: писать только движение и звук. Героя на картинке звать обобщённо, без пересказа его внешности.

## Тайминги

- Разметка времени - формат `[00:00-00:02]` с действием и звуком отрезка.
- Порядок событий Veo держит, а точную секунду и склейки - нет: в одном тесте склеек не вышло совсем, в другом склейка встала на 2,83 с вместо 4,00 с. Нужна точная склейка - отдельные ролики и монтаж.
- Звук к видимому событию привязывается точно, если оба названы в одном отрезке.
- Длительность только 4, 6 или 8 с. Только 8 с - для 1080p, 4K, опорных картинок и продления.

## Референсы

- Опорных картинок до 3, роль у них одна - сохранить вид героя, предмета или места (`asset`). В Vertex есть ещё одна роль `style`, в Gemini API её нет.
- Синтаксиса ссылок вроде `@Image1` нет. Опору называть словами по тому, что на ней: человек, предмет, место.
- С опорными картинками нельзя задать первый и последний кадр, и ролик только 8 с.
- Последний кадр задаётся только вместе с первым.
- Картинка с фотореальным человеком может вернуть пустой результат без ошибки. Тогда другая картинка или режим без неё.
- В CLI пользователя: `veo3_1` - только `start_image`; `veo3_1_lite` - `start_image` и `end_image`, при двух кадрах только 8 с. Опорных картинок в CLI нет; на сайте Higgsfield есть.
- Видео на вход принимает только продление (раздел ниже). Видео-референса для движения у Veo нет.

## Речь, звук, надписи, русский язык

- Реплика - с меткой говорящего. Как её оформить, Google пишет по-разному: в Gemini API и блоге - в кавычках; в Vertex - после двоеточия без кавычек, чтобы не появились субтитры. Не решено тестами. Осторожное правило: кавычки и прямой запрет субтитров описанием чистого кадра; если субтитры всё равно вышли - двоеточие без кавычек.
- Шумы и фон - отдельными предложениями с метками Google `SFX:` и `Ambient noise:`. Эмоцию реплики можно дать меткой `Emotion:`.
- Темп речи около 1,9 слова в секунду. Длинная реплика обрывается: в тесте 39 слов оборвало на 31-м. Реплика должна кончаться раньше конца ролика.
- Несколько говорящих: Veo путает, кому какая реплика. Каждому - уникальная метка с приметой и видимое действие перед репликой; лучше один говорящий на ролик.
- Голос между роликами не закрепляется: описание голоса повторять слово в слово и готовиться к расхождению.
- Латинская надпись в кавычках выходит точно. Без заданного текста на вывесках будут выдуманные слова - либо задать текст, либо описать поверхности без надписей.
- **Русская речь:**
  - реплика на русском выходит дословно, по тестам vc.ru и Хабра;
  - прямо указать, что персонаж говорит по-русски: без этого губы двигаются как в английской речи (мнение автора Хабра);
  - точность губ на русском толком не мерили: фраза короткая, лицо в камеру, важную речь проверять в ролике.
- Кириллица в кадре искажается. Русские надписи - только монтажом.

## Правка и продление

- Правки готового ролика словами нет. Инструменты добавить и убрать предмет в Flow (видеоредактор Google) работают на Veo 2 и без звука.
- Продление в Higgsfield недоступно.
- Продление существует только у самого Google:
  - Gemini API: по +7 с, до 148 с итога; предварительные модели с продлением закрыты 22.10.2026, на текущей не проверено;
  - Vertex: вход 1-30 с, +7 с, итог около 37 с.
- Без продления длинный сюжет - цепочкой роликов: последний кадр предыдущего как `start_image` следующего.

## Настройки запроса (Higgsfield CLI)

| Модель | Поле | Значения |
|---|---|---|
| `veo3_1` | `variant` | `veo-3-1-fast` (по умолч.), `veo-3-1-preview` |
| | `duration` | `4`, `6`, `8` (по умолч.) |
| | `aspect_ratio` | `16:9`, `9:16` |
| | `quality` | `basic` (по умолч.), `high`, `ultra`; судя по журналу изменений Higgsfield, `ultra` - 4K, не проверено |
| | `start_image` | первый кадр |
| `veo3_1_lite` | `aspect_ratio` | `16:9`, `9:16`, `auto` |
| | `generate_audio` | по умолч. `false` - для звука включать явно |
| | `start_image`, `end_image` | `end_image` только с `start_image`; при двух кадрах `duration` только 8 |

- В CLI пользователя нет: поля запретов (`negativePrompt`), seed, числа вариантов, опорных картинок, последнего кадра у `veo3_1`, продления.
- Длительность 8 с ставить при 1080p, 4K и опорных картинках - иначе запрос отклонят.

## Провалы

| Провал | Что делать |
|---|---|
| Субтитры поверх речи | Реплику после двоеточия без кавычек; описать чистый кадр без текста |
| Реплика оборвана | Короче реплика: около 1,9 слова в секунду и запас до конца ролика |
| Реплику сказал не тот | Уникальные метки говорящих, действие перед репликой, меньше говорящих |
| Склейка не на месте или её нет | Не полагаться на таймкод; отдельные ролики и монтаж |
| Выдуманные слова на вывесках | Задать текст в кавычках или описать поверхности без надписей |
| Случайная сцена | Точнее камера, место, свет и действие |
| Пустой результат с картинкой человека | Другая картинка или генерация без неё |
| Ролик без звука на Lite | Включить `generate_audio` |
| Чистовой ролик вышел черновым | Проверить, что `variant` - `veo-3-1-preview` |
| Губы не совпадают с русской речью | Прямо указать русский язык, короче фраза, лицо в камеру |
| Отказ на безобидном слове (например, «shoot» в смысле съёмки) | Заменить слово синонимом |

Текстом не лечится:

- точное время склейки и событий - монтаж;
- одинаковый голос в нескольких роликах - озвучка отдельно;
- русские надписи в кадре - монтаж;
- правка готового ролика и продление в Higgsfield - новая генерация от последнего кадра.
